## [2026-07-31] 홈 디렉터리 시작 및 cwd 자동 포커스

### 작업 내용
- `screens/explorer.py` — DirectoryTree 루트를 `Path.cwd()` → `Path.home()`으로 변경
- `screens/explorer.py` — `on_mount`에서 `set_timer(0.3, _expand_to_cwd)` 등록
- `screens/explorer.py` — `_expand_to_cwd` 비동기 메서드 추가
  - `cwd.relative_to(home)`으로 home → cwd 사이의 경로 파트 목록 계산
  - 루트 노드부터 각 파트를 순서대로 `expand()` 후, 최대 3초(100ms × 30회) 폴링으로 자식 노드 로드 대기
  - 해당 파트 이름의 자식 노드가 나타나면 다음 레벨로 이동, 없으면 조기 return
  - 최종 노드에 `select_node()` + `scroll_to_node(animate=False)` 적용
  - cwd가 home 하위가 아닌 경우 `ValueError` 캐치 후 아무 동작 하지 않음

### 주요 결정 사항
- **폴링 방식 채택**: DirectoryTree의 `_load_directory`는 `@work(thread=True)`로 구현된 비동기 스레드 작업이라 자식 노드 로드 완료 시점을 이벤트로 감지하기 어렵다. `asyncio.sleep(0.1)` 루프로 자식 목록을 반복 확인하는 폴링 방식이 가장 단순하고 안정적이다.
- **`set_timer(0.3, ...)`**: 화면이 마운트된 직후 트리 루트가 렌더링되기 전에 expand를 호출하면 아무 효과가 없다. 0.3초 딜레이로 루트 노드 초기 렌더링이 완료된 후 확장 로직을 실행한다.
- **`_current_dir` 초기값 유지**: 사용자가 노드를 선택하기 전에도 "현재 폴더 사용하기" 버튼이 cwd 기준으로 동작해야 하므로, 초기값은 `str(Path.cwd())`를 그대로 유지한다.
