# 홈 디렉터리 시작 및 cwd 자동 포커스 작업계획

## 목표

DirectoryTree가 `Path.cwd()`에서 시작하면 상위 폴더로 이동이 불가능하다.
`Path.home()`을 루트로 설정해 전체 홈 디렉터리를 탐색할 수 있도록 하되,
앱 실행 시 cwd까지 트리를 자동 확장하고 해당 노드로 스크롤·포커스한다.
이를 통해 사용자는 바로 작업 폴더에서 시작하면서도 상위 폴더로 자유롭게 이동할 수 있다.

## 작업 범위

- `screens/explorer.py` — DirectoryTree 루트를 `Path.home()`으로 변경, `on_mount`에서 cwd 자동 포커스 비동기 로직 추가

---

## 세부 작업 목록

### 1단계: DirectoryTree 루트를 Path.home()으로 변경

- [X] `compose()`에서 `DirectoryTree(Path.cwd())` → `DirectoryTree(Path.home())` 변경
- [X] `__init__`의 `_current_dir` 초기값을 `str(Path.cwd())`로 유지 (선택 기준은 cwd)

### 2단계: on_mount에서 cwd 자동 확장·포커스 구현

- [X] `on_mount`에서 `self.set_timer(0.1, self._expand_to_cwd)` 등록
- [X] `_expand_to_cwd` 비동기 메서드 구현:
  - `cwd`의 `home()` 대비 상대 경로 parts 계산
  - 루트 노드부터 각 part를 순서대로 `expand()` → 폴링(최대 3초, 100ms 간격)으로 자식 로드 대기 → 해당 자식 노드로 이동
  - 마지막 노드에 `select_node()` + `scroll_to_node()` 적용
  - cwd가 home 하위가 아니면 아무 동작 하지 않음 (fallback)

## 완료 기준

- 앱 실행 시 DirectoryTree 루트가 홈 디렉터리(`~/`)다.
- 앱 실행 직후 cwd까지 트리가 자동으로 펼쳐지고, 해당 폴더 노드가 포커스·스크롤된다.
- cwd 노드를 클릭(선택)하지 않아도 `_current_dir`가 cwd로 초기화되어 있어 "현재 폴더 사용하기" 버튼이 즉시 동작한다.
- 홈 상위 경로나 home과 다른 드라이브에서 실행해도 앱이 크래시하지 않는다 (fallback).
