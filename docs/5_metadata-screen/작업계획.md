# MetadataScreen 구현 작업계획

## 목표

ExplorerScreen에서 전달받은 MP3 파일 목록을 바탕으로 메타데이터를 확인하고 수정할 수 있는 두 번째 화면을 구현한다.
첫 번째 MP3 파일의 기존 태그를 읽어 필드 기본값으로 채우고, 사용자가 원하는 항목만 선택해 일괄 적용할 수 있도록 한다.

## 작업 범위

- `screens/metadata.py` 내 `MetadataScreen` 전체 구현
- 레이아웃: 우상단 닫기 버튼, 하단 수정 버튼, 중앙 메타데이터 설정 영역
- 공통 필드(앨범명·아티스트·연도): 기존 태그 읽기 + 편집 가능한 입력창
- 개별 필드(트랙명·트랙번호): 입력창 없이 자동 처리 안내 표기

## 세부 작업 목록

### 0단계: 의존성 추가

- [x] `requirements.txt`에 `xattr` 패키지 추가
- [x] `.venv`에 설치
  ```bash
  pip install xattr
  ```

### 1단계: 레이아웃 및 공통 컨트롤

- [x] 우상단 `닫기` 버튼 구현 (클릭 시 `self.app.pop_screen()`으로 탐색 화면 복귀)
- [x] 하단 `메타데이터 수정하기` 버튼 배치

### 2단계: 메타데이터 설정 목록 영역

- [x] 최상단 `전체 항목 선택/해제` 체크박스 구현 (기본값: 모두 선택)
  - 토글 시 하위 모든 항목 체크 상태 연동
- [x] `앨범명` 행: 체크박스 + `Input` 입력창
  - 선택된 폴더의 xattr `user.album` 1차 읽기
  - 없으면 `app.selected_folder`의 폴더명으로 자동 매핑
- [x] `아티스트` 행: 체크박스 + `Input` 입력창
  - 선택된 폴더의 xattr `user.artist` 1차 읽기, 없으면 빈칸
- [x] `연도` 행: 체크박스 + `Input` 입력창
  - 선택된 폴더의 xattr `user.year` 1차 읽기, 없으면 빈칸
- [x] `트랙명` 행: 체크박스 + 안내 `Label` (입력창 없음)
  - 표시 문구: `"파일명 기반 자동 정제 적용"`
- [x] `트랙번호` 행: 체크박스 + 안내 `Label` (입력창 없음)
  - 표시 문구: `"파일명 오름차순 기준 순번 자동 부여"`

## 완료 기준

- `xattr` 패키지가 설치되어 있고 `import xattr`이 정상 동작한다.
- 화면 진입 시 선택된 폴더의 xattr(`user.album`, `user.artist`, `user.year`)이 입력창에 자동으로 채워진다.
- 태그가 없는 경우 앨범명은 폴더명, 나머지는 빈칸으로 표시된다.
- `전체 항목 선택/해제` 체크박스가 하위 항목 전체와 연동된다.
- `닫기` 버튼 클릭 시 탐색 화면으로 복귀한다.
- `메타데이터 수정하기` 버튼이 하단에 표시된다 (실제 저장 로직은 Phase 6에서 연결).
