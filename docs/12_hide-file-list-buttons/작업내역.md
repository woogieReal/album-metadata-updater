## [2026-09-19] 파일 목록 화면에서 새로고침/앱 재시작 버튼 숨기기

### 작업 내용
- 탐색화면에서 "현재 폴더 사용하기"를 눌러 MP3 파일 목록 화면으로 전환하면, 그 화면 목적과 무관한 "새로고침"·"앱 재시작" 버튼이 계속 노출되던 문제를 수정함
- `ExplorerScreen._show_file_list()`에서 파일 목록 모드 진입 시 `#refresh-btn`, `#restart-btn`의 `display`를 `False`로 설정
- `ExplorerScreen._back_to_tree()`에서 폴더 탐색 화면으로 복귀 시 두 버튼의 `display`를 다시 `True`로 복원

### 주요 결정 사항
- **단축키 로직은 그대로 두고 버튼의 `display` 속성만 토글함**: `r`(새로고침), `Ctrl+R`(앱 재시작) 단축키는 화면 상태와 무관하게 계속 동작해야 하므로, `action_refresh`/`action_restart_app` 자체는 건드리지 않고 화면에 노출되는 버튼 위젯만 숨김/복원 처리함. 버튼을 완전히 제거(`remove`)하는 대신 `display` 토글을 택해 위젯 재생성 비용과 상태 관리 복잡도를 줄임

### 이슈 & 해결
- 별도 이슈 없이 계획대로 구현됨
- 실제 UI 클릭 흐름을 검증하기 위해 tmux 대신 Textual의 공식 테스트 하네스(`App.run_test()` + `Pilot`)를 사용함 — 실제 `#action-btn`/`#back-btn` 클릭 이벤트를 발생시켜 버튼 노출 상태를 단언(`assert`)했고, 실제 존재하는 MP3 폴더(`~/Documents/Song for My Father `)로 읽기 전용 스캔만 수행해 원본 파일에는 영향 없이 검증함

### 변경 파일
- `screens/explorer.py`: `_show_file_list()`/`_back_to_tree()`에 버튼 표시/숨김 토글 로직 추가
