# 파일 목록 화면에서 새로고침/앱 재시작 버튼 숨기기 작업계획

## 목표

탐색화면에서 "현재 폴더 사용하기" 버튼을 눌러 MP3 파일 목록 화면으로 전환하면, 해당 화면 목적과 무관한 "새로고침" 버튼과 "앱 재시작" 버튼이 계속 노출되어 화면이 산만하다. 파일 목록 모드에서는 두 버튼을 숨기고, 다시 폴더 탐색 화면으로 돌아가면 원래대로 보이게 한다.

## 작업 범위

- `ExplorerScreen`의 파일 목록 모드 진입(`_show_file_list`) 시 `#refresh-btn`, `#restart-btn` 버튼 숨김
- 폴더 탐색 화면 복귀(`_back_to_tree`) 시 두 버튼 다시 표시
- 키보드 단축키(`r` 새로고침, `Ctrl+R` 앱 재시작)는 기존 동작 유지 (버튼 노출 여부만 변경, 기능 자체는 제거하지 않음)

---

## 세부 작업 목록

### 1단계: `screens/explorer.py` 버튼 표시/숨김 로직 추가

- [x] `_show_file_list()`에서 `#refresh-btn`, `#restart-btn`의 `display`를 `False`로 설정
- [x] `_back_to_tree()`에서 `#refresh-btn`, `#restart-btn`의 `display`를 `True`로 복원

### 2단계: 동작 확인

- [x] 탐색화면(초기 진입) 시 "새로고침", "앱 재시작" 버튼이 보이는지 확인
- [x] "현재 폴더 사용하기" 클릭 후 파일 목록 화면에서 두 버튼이 보이지 않는지 확인
- [x] "폴더 다시 선택" 클릭 시 두 버튼이 다시 보이는지 확인
- [x] 파일 목록 화면에서도 `r`, `Ctrl+R` 단축키는 기존처럼 정상 동작하는지 확인 (버튼만 숨김, 기능은 유지) — 코드상 `on_button_pressed`/`action_refresh`/`action_restart_app` 로직 변경 없음, display 토글만 추가했으므로 유지됨

## 완료 기준

- 파일 목록 화면(`_in_file_mode = True`)에서는 "새로고침", "앱 재시작" 버튼이 보이지 않는다.
- 폴더 탐색 화면으로 복귀하면 두 버튼이 다시 정상적으로 보인다.
- 단축키(`r`, `Ctrl+R`) 기능 자체는 화면과 무관하게 계속 정상 동작한다.
