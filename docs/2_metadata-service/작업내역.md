## [2026-07-30] MetadataService 구현

### 작업 내용
- `services/metadata_service.py`에 `MetadataService` 클래스 전체 구현
- `read_tags(filepath)`: mutagen ID3로 `TALB`, `TPE1`, `TDRC`, `TIT2`, `TRCK` 5개 필드 읽기. 태그 없는 필드는 `None`, ID3 헤더 자체가 없는 파일은 빈 dict 반환
- `clean_track_title(filename)`: 확장자 제거 후 정규표현식으로 앞부분 트랙번호 패턴 제거하여 정제된 트랙명 반환
- `assign_track_numbers(filepaths)`: 파일명 기준 오름차순 정렬 후 `(filepath, 순번)` 튜플 리스트 반환
- `write_tags(filepath, tags)`: ID3 태그 일괄 저장, 성공 시 `True` / 예외 시 로깅 후 `False` 반환
- 5가지 변환 케이스(`01 -`, `02.`, `[03]`, `4)`, 번호 없음) 검증 스크립트로 전체 통과 확인

### 주요 결정 사항
- `write_tags()`에서 `ID3NoHeaderError` 발생 시 `ID3()`로 빈 태그 객체를 새로 생성해 덮어쓰는 방식 채택
  - 태그가 전혀 없는 파일도 신규 태그 삽입이 가능하도록 하기 위함
- `write_tags()`의 frame 생성 로직을 `mapping` dict로 선언적으로 구성
  - 나중에 지원 필드 추가/제거가 한 줄로 가능해 유지보수성 확보
- `assign_track_numbers()`는 전체 경로가 아닌 `os.path.basename()`으로 파일명만 추출해 정렬
  - 폴더 경로가 달라도 파일명 기준으로 일관된 정렬이 되도록 하기 위함

### 이슈 & 해결
- IDE에서 `mutagen.id3` 모듈을 찾지 못하는 오류 발생
  - 원인: IDE가 시스템 Python(`/Library/.../Python3.9`)을 바라보고 있어 `.venv`의 패키지를 인식하지 못함
  - 해결: IDE 인터프리터를 `.venv/bin/python3`으로 변경하도록 가이드 제공 (코드 자체 문제 아님)
