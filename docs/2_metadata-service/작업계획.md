# MetadataService 구현 작업계획

## 목표

MP3 파일의 ID3 태그를 읽고 쓰는 핵심 서비스 레이어를 구현한다.
파일명에서 트랙명을 자동 정제하고 트랙번호를 순서대로 부여하는 비즈니스 로직을 MetadataService에 집중시켜,
이후 화면(Screen) 레이어가 서비스만 호출하면 되는 깔끔한 구조를 만든다.

## 작업 범위

- `services/metadata_service.py` 내 MetadataService 클래스 구현
- ID3 태그 읽기 / 쓰기 메서드
- 파일명 정제(트랙명 추출) 메서드
- 트랙번호 부여 메서드

---

## 세부 작업 목록

### 1단계: ID3 태그 읽기 메서드 구현

- [ ] `read_tags(filepath: str) -> dict` 메서드 구현
  - `mutagen.id3.ID3`로 파일 로드
  - `TALB`(앨범명), `TPE1`(아티스트), `TDRC`(연도), `TIT2`(트랙명), `TRCK`(트랙번호) 추출
  - 태그가 없는 필드는 `None` 반환
  - ID3 태그 자체가 없는 파일(`ID3NoHeaderError`)은 빈 dict 반환

### 2단계: 파일명 정제(트랙명 추출) 메서드 구현

- [ ] `clean_track_title(filename: str) -> str` 메서드 구현
  - `.mp3` 확장자 제거
  - 정규표현식 `r'^\s*(\d+|\[\d+\])[\s._\-)]*'` 으로 앞부분 트랙번호 패턴 제거
  - 앞뒤 공백 제거 후 정제된 트랙명 반환
  - 변환 예시: `01 - Sony Music.mp3` → `Sony Music`

### 3단계: 트랙번호 부여 메서드 구현

- [ ] `assign_track_numbers(filepaths: list[str]) -> list[tuple[str, int]]` 메서드 구현
  - 입력된 파일 경로 목록을 파일명 기준 오름차순 정렬
  - 정렬 순서대로 `(filepath, 순번)` 튜플 리스트 반환 (순번은 1부터 시작)

### 4단계: ID3 태그 일괄 쓰기 메서드 구현

- [ ] `write_tags(filepath: str, tags: dict) -> bool` 메서드 구현
  - `tags` dict의 키: `album`, `artist`, `year`, `title`, `track_number` (없는 키는 스킵)
  - `mutagen.id3.ID3`로 파일 로드, 태그가 없으면 새로 생성 (`ID3NoHeaderError` 처리)
  - 각 키에 대응하는 ID3 프레임 (`TALB`, `TPE1`, `TDRC`, `TIT2`, `TRCK`) 세팅 후 `save()`
  - 성공 시 `True`, 예외 발생 시 예외 메시지를 로깅하고 `False` 반환

## 완료 기준

- `read_tags()`가 유효한 MP3 파일에서 ID3 태그 dict를 반환한다.
- `clean_track_title()`이 `01 - Sony Music.mp3` → `Sony Music` 변환을 정확히 수행한다.
- `assign_track_numbers()`가 파일명 오름차순으로 정렬된 `(filepath, 순번)` 리스트를 반환한다.
- `write_tags()`가 MP3 파일에 태그를 성공적으로 기록하고 `True`를 반환한다.
- 태그 없는 파일, 잘못된 경로 등 예외 상황에서 크래시 없이 안전하게 처리된다.
