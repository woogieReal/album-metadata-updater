# 프로젝트 초기 설정 작업계획

## 목표

Textual 기반 TUI 앱을 개발하기 위한 Python 가상환경을 구성하고, 필요한 의존성(`textual`, `mutagen`)을 `requirements.txt`로 관리한다.
앱의 기능 단위(App, Screen, Service)에 맞는 디렉터리 구조를 미리 잡아 이후 단계별 작업이 일관된 구조 위에서 진행되도록 한다.

## 작업 범위

- Python 가상환경(`.venv`) 생성 및 활성화 가이드
- `requirements.txt` 파일 생성 및 의존성 설치
- 프로젝트 디렉터리 및 빈 파일 뼈대 생성
- `.gitignore`에 `.venv/` 추가

---

## 세부 작업 목록

### 1단계: 가상환경 생성 및 활성화

- [ ] 프로젝트 루트에서 아래 명령어로 가상환경 생성
  ```bash
  python3 -m venv .venv
  ```
- [ ] 가상환경 활성화
  ```bash
  source .venv/bin/activate
  ```

### 2단계: 의존성 파일 작성 및 설치

- [ ] 프로젝트 루트에 `requirements.txt` 파일 생성 후 아래 내용 작성
  ```
  textual
  mutagen
  ```
- [ ] 패키지 설치
  ```bash
  pip install -r requirements.txt
  ```

### 3단계: 프로젝트 디렉터리 구조 생성

- [ ] 아래 파일 뼈대 생성 (내용은 비워둬도 무방)
  - `main.py` — 앱 진입점
  - `app.py` — `AlbumTagApp` 클래스
  - `screens/` 디렉터리 생성
    - `screens/__init__.py`
    - `screens/explorer.py` — `ExplorerScreen`
    - `screens/metadata.py` — `MetadataScreen`
  - `services/` 디렉터리 생성
    - `services/__init__.py`
    - `services/metadata_service.py` — `MetadataService`

### 4단계: .gitignore 설정

- [ ] 프로젝트 루트의 `.gitignore`에 `.venv/` 항목 추가

---

## 변경 대상 파일

| 파일 | 변경 내용 |
|------|-----------|
| `.venv/` | 가상환경 디렉터리 (git 추적 제외) |
| `requirements.txt` | 신규 생성 — `textual`, `mutagen` 기록 |
| `main.py` | 신규 생성 — 진입점 뼈대 |
| `app.py` | 신규 생성 — `AlbumTagApp` 뼈대 |
| `screens/__init__.py` | 신규 생성 |
| `screens/explorer.py` | 신규 생성 — `ExplorerScreen` 뼈대 |
| `screens/metadata.py` | 신규 생성 — `MetadataScreen` 뼈대 |
| `services/__init__.py` | 신규 생성 |
| `services/metadata_service.py` | 신규 생성 — `MetadataService` 뼈대 |
| `.gitignore` | `.venv/` 항목 추가 |

---

## 완료 기준

- `source .venv/bin/activate` 후 `pip list`에 `textual`, `mutagen` 패키지가 표시된다.
- 위 표의 모든 파일 및 디렉터리가 프로젝트 루트에 존재한다.
- `.gitignore`에 `.venv/`가 포함되어 있어 가상환경이 git에 추적되지 않는다.
