- 가상환경 활성화(`source .venv/bin/activate`) 없이 `.venv/bin/pip`을 직접 호출하여 설치 진행
  - 셸 상태가 세션 간 유지되지 않는 CLI 환경 특성상 활성화 명령이 다음 커맨드에 영향을 주지 않기 때문
  - 실제 개발 시에는 `source .venv/bin/activate`로 활성화 후 사용하면 됨
- 뼈대 파일은 클래스 선언만 포함한 최소한의 내용으로 작성
