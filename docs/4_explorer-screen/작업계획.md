# ExplorerScreen 구현 작업계획

## 목표

사용자가 디렉터리를 탐색하고 대상 MP3 파일을 선택하는 첫 번째 화면을 구현한다.
탐색 모드 → 파일 선택 모드 두 가지 상태를 하나의 화면 안에서 전환하며,
선택이 완료되면 체크된 파일 목록을 들고 MetadataScreen으로 이동한다.

## 작업 범위

- `screens/explorer.py` 내 `ExplorerScreen` 전체 구현
- 상태 1: DirectoryTree 기반 디렉터리 탐색
- 상태 2: MP3 파일 목록 + 체크박스
- MetadataScreen으로의 화면 전환

---

## 세부 작업 목록

### 1단계: 상태 1 — 디렉터리 탐색 모드

- [x] `DirectoryTree("/")`로 루트부터 전체 파일시스템 탐색 가능하도록 구성
- [x] 하단에 `현재 폴더 사용하기` 버튼(`Button`) 배치
- [x] `on_directory_tree_directory_selected()` 핸들러로 선택된 디렉터리 경로를 내부 상태(`_current_dir`)에 저장

### 2단계: 상태 2 — MP3 파일 목록 및 체크박스

- [x] `현재 폴더 사용하기` 버튼 클릭 시 선택된 폴더 하위 `.mp3` 파일만 필터링하여 목록 추출
  - `pathlib.Path.glob("*.mp3")` 사용 (대소문자 구분 없이 처리)
- [x] `DirectoryTree` 영역을 숨기고 파일 목록 영역(`ListView` 또는 `ScrollableContainer`)을 표시
- [x] 최상단 `전체 선택/해제` 체크박스(`Checkbox`) 구현
  - 토글 시 하위 모든 항목 체크 상태 연동
- [x] 추출된 MP3 파일명별 개별 체크박스 렌더링 (기본값: 모두 선택)
- [x] `현재 폴더 사용하기` 버튼 라벨을 `설정할 메타데이터 고르기`로 교체

### 3단계: MetadataScreen 전환

- [x] `설정할 메타데이터 고르기` 버튼 클릭 시 체크된 파일 절대 경로 목록 수집
- [x] `app.selected_folder`, `app.selected_files` 에 값 저장
- [x] `self.app.push_screen(MetadataScreen(selected_files))` 로 화면 전환

| 파일 | 변경 내용 |
|------|-----------|

## 완료 기준

- 앱 실행 시 루트(`/`)부터 디렉터리 탐색이 가능하다.
- 폴더를 선택하고 `현재 폴더 사용하기`를 누르면 해당 폴더의 `.mp3` 파일 목록이 체크박스와 함께 표시된다.
- 전체 선택/해제 체크박스가 하위 항목 전체와 연동된다.
- `설정할 메타데이터 고르기` 버튼 클릭 시 `MetadataScreen`으로 화면이 전환된다.
- MP3 파일이 없는 폴더를 선택했을 때 빈 목록이 표시되고 크래시가 발생하지 않는다.
