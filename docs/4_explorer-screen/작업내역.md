## [2026-07-30] ExplorerScreen 구현

### 작업 내용
- `screens/explorer.py` — `ExplorerScreen` 전체 구현
  - `compose()`: `DirectoryTree("/")`, `ScrollableContainer`(파일 목록), `Button`(하단) 배치
  - `on_directory_tree_directory_selected()`: 선택된 디렉터리 경로를 `_current_dir`에 저장
  - `_show_file_list()`: 버튼 클릭 시 `.mp3` 파일 필터링 → 체크박스 목록 마운트 → 트리 숨김 → 버튼 라벨 교체
  - `on_checkbox_changed()`: `전체 선택/해제` 체크박스 토글 시 하위 항목 전체 연동
  - `_go_to_metadata()`: 체크된 파일 수집 → `app.selected_folder` / `app.selected_files` 저장 → `MetadataScreen` push
- `screens/metadata.py` — 생성자에서 `selected_files: List[str]` 인자 수신하도록 수정

### 주요 결정 사항
- 체크박스 ID를 파일명 대신 인덱스 기반(`file-0`, `file-1`, ...)으로 부여
  - 파일명에 공백, 점, 특수문자 등이 포함된 경우 CSS 셀렉터가 깨지는 문제를 방지하기 위함
- `_syncing` 플래그를 도입해 `전체 선택/해제` 토글 시 하위 체크박스 변경 이벤트가 다시 `on_checkbox_changed`를 트리거하는 무한 루프를 차단
- `.mp3` 필터링 시 `glob("*.mp3")` 대신 `iterdir()` + `suffix.lower() == ".mp3"` 조합 사용
  - macOS 파일시스템이 대소문자를 구분하지 않는 경우에도 `.MP3` 확장자를 명시적으로 커버하기 위함
- 두 가지 화면 상태(탐색 모드 / 파일 선택 모드)를 별도 Screen으로 나누지 않고 `display` 토글로 단일 Screen 내에서 처리
  - Screen 전환 없이 상태만 바꾸므로 화면 깜빡임 없이 자연스러운 전환 가능
