# AlbumTagApp 구현 작업계획

## 목표

Textual의 `App` 클래스를 상속해 앱 전체의 진입점이자 전역 상태 저장소 역할을 하는 `AlbumTagApp`을 완성한다.
선택된 폴더 경로와 체크된 MP3 파일 목록을 앱 레벨에서 관리함으로써, 화면 간 데이터 전달을 단순하게 유지한다.

## 작업 범위

- `app.py` 내 `AlbumTagApp` 클래스 구현
- 전역 상태 속성 정의 (선택 폴더 경로, 체크된 MP3 파일 목록)
- 초기 화면 `ExplorerScreen` 마운트 설정

---

## 세부 작업 목록

### 1단계: AlbumTagApp 클래스 작성

- [ ] `textual.app.App`을 상속하는 `AlbumTagApp` 클래스 작성
- [ ] 앱 타이틀 설정 (`TITLE = "앨범 메타데이터 업데이터"`)

### 2단계: 전역 상태 속성 정의

- [ ] `selected_folder: str | None` — 탐색 화면에서 사용자가 선택한 폴더 경로 (초기값 `None`)
- [ ] `selected_files: list[str]` — 체크된 MP3 파일의 절대 경로 목록 (초기값 빈 리스트)

### 3단계: 초기 화면 설정

- [ ] `on_mount()` 에서 `self.push_screen(ExplorerScreen())`으로 탐색 화면을 첫 화면으로 설정

|------|-----------|
| `app.py` | `AlbumTagApp` 클래스 구현 (전역 상태, 초기 화면 설정) |

---

## 완료 기준

- `python main.py` 실행 시 TUI가 정상적으로 실행되고 `ExplorerScreen`이 첫 화면으로 표시된다.
- `app.selected_folder`, `app.selected_files` 속성이 앱 어디서든 접근 가능하다.
