## [2026-07-30] AlbumTagApp 전역 상태 및 타이틀 설정

### 작업 내용
- `app.py`에 `TITLE = "앨범 메타데이터 업데이터"` 설정
- `selected_folder: Optional[str] = None` — 탐색 화면에서 선택한 폴더 경로 전역 상태 추가
- `selected_files: list = []` — 체크된 MP3 파일 절대 경로 목록 전역 상태 추가
- `on_mount()`는 기존과 동일하게 `ExplorerScreen`을 첫 화면으로 push

### 주요 결정 사항
- 전역 상태를 `App` 클래스 속성으로 선언해 어느 화면에서든 `self.app.selected_folder` 형태로 직접 접근 가능하도록 설계
  - 화면 간 데이터를 생성자 인자로 넘기지 않아도 되어 화면 전환 코드가 단순해짐
- `selected_files`의 타입 힌트를 `list[str]` 대신 `list`로 선언
  - Python 3.9에서는 `list[str]` 클래스 변수 선언이 지원되지 않아 제네릭 없이 `list` 사용

### 이슈 & 해결
- `selected_folder: str | None = None` 선언 시 `TypeError: unsupported operand type(s) for |` 발생
  - 원인: `X | Y` 유니온 문법은 Python 3.10+에서만 지원되며, 현재 환경은 Python 3.9
  - 해결: `from typing import Optional`을 import하고 `Optional[str]`로 교체

### 변경 파일
- `app.py` (수정 — TITLE, selected_folder, selected_files 추가)
