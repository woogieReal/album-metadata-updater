## [2026-07-31] UX 개선 — 탐색화면 시작 경로 및 메타화면 복귀 동작

### 작업 내용
- `screens/explorer.py` — DirectoryTree 시작 경로 변경
  - `DirectoryTree("/")` → `DirectoryTree(Path.cwd())`
  - `_current_dir` 초기값 `"/"` → `str(Path.cwd())`
- `screens/explorer.py` — `_go_to_metadata()` 에서 `push_screen()` 직전 트리 모드 복원 로직 추가

  - `#file-list-container` display = False
  - `#action-btn` label = "현재 폴더 사용하기"
  - `_in_file_mode = False`

### 주요 결정 사항
- 트리 모드 복원 위치를 `push_screen()` 직전으로 선택
  - `pop_screen()` 이벤트를 후처리하는 방식(`on_screen_resume` 등)도 가능하나, 전환 시점에 명시적으로 상태를 초기화하는 것이 흐름이 더 명확함
  - DirectoryTree 위젯 인스턴스는 스택에 살아있으므로 펼쳐진 폴더 상태가 자동으로 보존됨 — 별도 상태 저장 불필요
