# UX 개선 — 탐색화면 시작 경로 및 메타화면 복귀 동작 작업계획

## 목표

실사용 중 발견된 두 가지 UX 불편을 해소한다.
DirectoryTree가 루트(`/`)에서 시작하는 탓에 목표 폴더까지 탐색이 번거로우며,
MetadataScreen을 닫고 돌아왔을 때 파일 목록 모드에 갇혀 다른 폴더를 선택할 수 없다.
두 개선을 통해 앱의 실사용 흐름을 자연스럽게 만든다.

## 작업 범위

- `screens/explorer.py` — DirectoryTree 시작 경로 변경 및 메타화면 전환 전 트리 모드 복원

---

## 세부 작업 목록

### 1단계: DirectoryTree 시작 경로 변경

- [X] `compose()`에서 `DirectoryTree("/")` → `DirectoryTree(Path.cwd())` 로 변경
- [X] `__init__`의 `_current_dir` 초기값도 `str(Path.cwd())` 로 변경

### 2단계: MetadataScreen 전환 전 트리 모드 복원

- [X] `_go_to_metadata()` 에서 `push_screen()` 호출 직전에 ExplorerScreen을 트리 모드로 복원
  - `#tree-container` display = True
  - `#file-list-container` display = False
  - `#action-btn` label = "현재 폴더 사용하기"
  - `_in_file_mode = False`
- [X] 메타화면 닫기(`pop_screen`) 또는 수정 완료 후 ExplorerScreen 복귀 시 이전 트리 상태(펼쳐진 폴더)가 그대로 유지되는지 확인

---

## 변경 대상 파일

| 파일 | 변경 내용 |
|------|-----------|
| `screens/explorer.py` | DirectoryTree 시작 경로를 `Path.cwd()`로 변경, `_go_to_metadata()`에서 트리 모드 복원 로직 추가 |

---

## 완료 기준

- 앱 실행 시 DirectoryTree가 실행 디렉터리에서 시작한다.
- MetadataScreen 닫기 후 탐색화면에 이전에 펼쳐져 있던 디렉터리 트리가 그대로 표시된다.
- 트리에서 다른 폴더를 즉시 선택해 다시 메타화면으로 진행할 수 있다.
