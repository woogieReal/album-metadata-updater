### 주요 결정 사항
- **`DirectoryTree.reload()` 활용**: Textual 내부 `_reload`는 현재 열려 있는 노드들의 경로 집합(`currently_open: set[Path]`)을 저장한 뒤 리셋하고, 기존에 열려 있던 경로들을 다시 expand/populate하므로 사용자가 작업 중이던 트리 탐색 상태를 그대로 보존하면서 파일시스템 변경분만 완벽하게 갱신한다.
- **`remove_children()` 비동기 대기**: Textual 위젯 컨테이너에서 자식 위젯을 제거하는 작업은 비동기로 unmount되므로, 동기식으로 즉시 새 체크박스를 mount할 경우 `DuplicateIds` 충돌이 발생할 수 있다. 이를 방지하기 위해 `await file_list.remove_children()` 후 `await file_list.mount_all(...)`을 호출하도록 구조를 개선했다.
- **`폴더 다시 선택` 버튼 지원**: 사용자가 폴더를 선택하고 파일 목록 화면에 진입한 뒤에도 다른 폴더로 다시 이동하고 싶을 때 직관적으로 복귀할 수 있도록 UI를 개선했다.

### 이슈 & 해결
- **이슈**: 파일 목록 화면에서 새로고침 실행 시 자식 체크박스 위젯 삭제 완료 전 동일 ID(`select-all`) 위젯이 추가되어 `DuplicateIds` 예외 발생
- **해결**: `_show_file_list`와 `on_button_pressed`를 `async`로 전환하고 `await remove_children()` 및 `await mount_all()`을 사용하여 DOM 갱신 작업의 순서를 완전히 동기화함.
