# 파일 트리 새로고침(Refresh) 작업계획

## 목표

앱 실행 중 파일시스템에 파일이나 폴더가 새로 생성·삭제·수정된 경우,
현재 사용자가 펼쳐둔 디렉터리 트리 상태(`is_expanded`)와 선택 위치를 그대로 유지하면서
파일시스템을 다시 읽어들여 최신 파일트리를 갱신하는 새로고침 기능을 제공한다.
또한 단축키(`r`)와 화면 버튼(`새로고침`, `폴더 다시 선택`)을 제공하여 조작 편의성을 극대화한다.

## 작업 범위

- `screens/explorer.py` — `DirectoryTree.reload()` 연동, `r` 키 바인딩, `새로고침` / `폴더 다시 선택` 버튼, `Footer` 추가, 비동기 DOM 처리 개선
- `README.md` — 새로고침 기능 및 단축키/버튼 조작 설명 문서화
- `docs/workstep.md` — Phase 10 작업 단계 추가 및 완료 체크

## 완료 기준

- 하위 디렉터리가 펼쳐진 상태에서 새로고침(`r` 또는 버튼)을 수행해도 펼쳐진 상태가 그대로 유지된다.
- 파일시스템에 새로 추가/삭제된 폴더나 MP3 파일이 새로고침 즉시 트리에 반영된다.
- 파일 목록 모드에서도 `r` 또는 새로고침 버튼으로 최신 파일 목록이 갱신된다.
- 파일 목록 모드에서 `폴더 다시 선택` 버튼을 누르면 폴더 탐색 트리로 정상 복귀한다.
- `README.md` 및 프로젝트 문서에 해당 기능 사용법이 누락 없이 기술된다.
