```
[초기 실행] Footer: "r 새로고침  ^r 앱 재시작"  (두 바인딩 동시 노출, 충돌 없음)
[PID 확인]   12077 /.../Python main.py

[Ctrl+R 1차 전송]
  → 재실행 후 PID 그대로 12077 유지, 화면이 초기 탐색기 화면으로 정상 재렌더링

[app.py의 TITLE을 "앨범 메타데이터 업데이터 [RELOAD-TEST]"로 임시 수정 후 저장]
[Ctrl+R 2차 전송]
  → 재실행 후 헤더에 "앨범 메타데이터 업데이터 [RELOAD-TEST]" 즉시 반영 확인
  → PID 여전히 12077 유지 (프로세스 교체이나 동일 PID)

[TITLE 원복 후 Ctrl+R 3차 전송]
  → 헤더가 "앨범 메타데이터 업데이터"로 정상 복귀

[Ctrl+Q로 정상 종료 → 프로세스(12077) 완전히 사라짐, tmux 세션 정리 완료]
```

> 참고: 테스트 중 별도로 이미 실행 중이던 사용자 프로세스(PID 4334, 다른 tty)가 존재함을 확인했으며, 이는 건드리지 않고 신규 tmux 세션(PID 12077)에서만 격리 테스트함.
