# 앱 재실행(코드 리로드) 기능 작업계획

## 목표

개발 중 코드를 수정할 때마다 터미널을 닫고 앱을 다시 실행해야 하는 번거로움을 없앤다. 앱 안에서 단축키(Ctrl+R) 또는 버튼으로 프로세스를 재실행하면, 저장된 코드 변경사항이 반영된 상태로 앱이 다시 뜬다.

## 작업 범위

- Textual 앱을 정상 종료(`App.exit()`) 후, `main.py`에서 프로세스를 재실행(`os.execv`)하는 재시작 로직 구현
- `Ctrl+R` 단축키 추가 (전역, 모든 화면에서 동작)
- `ExplorerScreen` 하단바에 "앱 재시작" 버튼 추가
- 기존 `r` 키(파일 트리 새로고침, `screens/explorer.py:16-17`)와의 충돌 없음을 확인

## 세부 작업 목록

### 1단계: 앱 재시작 플래그 및 액션 추가 (`app.py`)

- [x] `AlbumTagApp`에 `restart_requested: bool = False` 속성 추가
- [x] `BINDINGS = [Binding("ctrl+r", "restart_app", "앱 재시작")]` 추가
- [x] `action_restart_app()` 구현: `restart_requested = True` 설정 후 `self.exit()` 호출

### 2단계: 프로세스 재실행 로직 추가 (`main.py`)

- [x] `app.run()` 종료 후 `app.restart_requested`가 `True`이면 `os.execv(sys.executable, [sys.executable] + sys.argv)` 호출
- [x] `os`, `sys` 모듈 import 추가

### 3단계: 하단바 재시작 버튼 추가 (`screens/explorer.py`)

- [x] 하단 `Horizontal` 버튼 바에 `Button("앱 재시작", id="restart-btn")` 추가
- [x] `on_button_pressed`에서 `restart-btn` 클릭 시 `self.app.action_restart_app()` 호출

### 4단계: 동작 확인

- [x] `run_app.command`로 앱 실행 후 코드 한 줄 수정 → `Ctrl+R` → 변경사항이 반영된 채 재실행되는지 확인 (tmux pty로 실측)
- [x] 재실행 후 터미널 상태(줄바꿈, 커서, 색상 등)가 깨지지 않는지 확인
- [x] `ExplorerScreen`의 기존 `r`(새로고침) 단축키가 그대로 정상 동작하는지 확인 (Footer에 `r 새로고침`/`^r 앱 재시작` 동시 표시, 충돌 없음)
- [ ] `MetadataScreen` 등 다른 화면에서도 `Ctrl+R`이 정상 동작하는지 확인 (미검증 — App 레벨 바인딩이라 이론상 동작하나 실측은 안 함)

## 완료 기준

- `Ctrl+R` 또는 "앱 재시작" 버튼 클릭 시, 터미널을 닫지 않고도 코드 변경사항이 반영된 새 프로세스로 앱이 재실행된다.
- 재실행 과정에서 터미널 화면이 깨지거나 잔상이 남지 않는다.
- 기존 `r`(파일 트리 새로고침) 기능은 영향받지 않고 그대로 동작한다.
