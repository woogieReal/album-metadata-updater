# 통합 테스트 및 마무리 작업계획

## 목표

Phase 1~6에서 구현된 전체 기능을 통합적으로 검증하고 앱을 완성한다.
엣지 케이스(MP3 없는 폴더, 파일/항목 미선택 상태)에 대한 방어 처리를 추가하고,
UI 스타일 및 레이아웃을 최종 정리하여 실사용 가능한 상태로 마무리한다.

## 작업 범위

- `screens/explorer.py` — 엣지 케이스 방어 처리
- `screens/metadata.py` — 엣지 케이스 방어 처리
- UI 스타일 최종 점검 및 정리

---

## 세부 작업 목록

### 1단계: 전체 플로우 통합 테스트

- [x] 앱 실행 후 디렉터리 탐색 → MP3 폴더 선택 → `현재 폴더 사용하기` 클릭
- [x] 파일 목록 확인 및 체크박스 선택/해제 동작 확인
- [x] `설정할 메타데이터 고르기` 클릭 → MetadataScreen 전환 확인
- [x] 폴더 xattr 값이 앨범명·아티스트·연도에 자동 입력되는지 확인
- [x] `메타데이터 수정하기` 클릭 후 Toast 알림 및 화면 복귀 확인

### 2단계: 엣지 케이스 처리

- [x] 선택 폴더에 MP3 파일이 없을 때 안내 메시지 표시 (파일 목록 화면으로 전환 방지)
- [x] 체크된 파일이 없는 상태에서 `설정할 메타데이터 고르기` 버튼 클릭 방지 및 안내
- [x] 체크된 항목이 없는 상태에서 `메타데이터 수정하기` 버튼 클릭 방지 및 안내

### 3단계: UI 스타일 및 레이아웃 최종 정리

- [x] 각 화면의 버튼·위젯 간격 및 정렬 점검
- [x] 불필요한 CSS 정리 및 일관성 확보

---

## 변경 대상 파일

| 파일 | 변경 내용 |
|------|-----------|
| `screens/explorer.py` | MP3 없는 폴더 안내, 파일 미선택 시 버튼 클릭 방지 |
| `screens/metadata.py` | 항목 미선택 시 수정 버튼 클릭 방지 |

---

## 완료 기준

- 전체 플로우(탐색 → 선택 → 메타데이터 설정 → 수정)가 오류 없이 동작한다.
- MP3 파일이 없는 폴더 선택 시 적절한 안내 메시지가 표시된다.
- 파일이 하나도 체크되지 않은 상태에서 다음 단계로 진행되지 않는다.
- 메타데이터 항목이 하나도 체크되지 않은 상태에서 수정이 실행되지 않는다.
