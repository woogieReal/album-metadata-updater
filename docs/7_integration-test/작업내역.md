### 주요 결정 사항
- 방어 로직을 버튼 핸들러가 아닌 실행 메서드 진입부에 배치
  - `_show_file_list`, `_go_to_metadata`, `_apply_metadata` 각각의 책임 범위 안에서 방어하도록 배치해 응집도 유지
- `severity="warning"` 사용 (error 아님)
  - 사용자 실수로 인한 상황이므로 error보다 낮은 수준의 경고가 적합
- Textual Pilot API로 자동화 테스트 진행
  - tmux 수동 테스트는 한글 버튼 라벨의 포커스 시각 확인이 어려워 신뢰성이 낮음
  - `app.run_test()`로 위젯 상태를 직접 제어하는 방식이 더 정확한 검증 방법임을 확인
