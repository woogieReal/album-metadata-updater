
# 앨범 메타데이터 자동 갱신 TUI 앱 설계안

## 1. 아키텍처 및 클래스 구조

* **`AlbumTagApp (App)`**: 앱의 메인 상태(선택된 폴더, 대상 MP3 파일 목록 등)를 관리하는 중앙 애플리케이션 클래스.
* **`ExplorerScreen (Screen)`**: 디렉터리 탐색 및 대상 MP3 파일 선택을 담당하는 **탐색 화면**.
* **`MetadataScreen (Screen)`**: 앨범 공통 정보 및 트랙 메타데이터를 설정하고 일괄 적용하는 **메타 화면**.
* **`MetadataService`**: mutagen(ID3)을 이용한 MP3 태그 읽기/쓰기 및 정규표현식 기반 파일명 정제 로직 전담.

---

## 2. 화면별 UI 구성 및 동작 흐름

### A. 탐색 화면 (`ExplorerScreen`)

1. **상태 1: 디렉터리 탐색 모드 (앱 최초 실행 시)**
* **`DirectoryTree`**: 앱 실행 위치에 국한되지 않고 전체 디렉터리 탐색 가능.
* **하단 버튼**: `현재 폴더 사용하기` (이하 **사용 버튼**)


2. **상태 2: 대상 폴더 선택 후 (**사용 버튼** 클릭 시)**
* **파일 필터링 규칙**: 선택한 폴더 하위의 **`.mp3` 확장자 파일만 추출**하여 나열합니다. (디렉터리 및 타 포맷 파일은 제외)
* **파일 목록 영역**:
* 최상단: `[x] 전체 선택/해제` 체크박스
* 하위 항목: 추출된 MP3 파일명 목록 및 개별 체크박스 (기본값: 모두 선택됨)


* **버튼 전환**: 기존 **사용 버튼** 자리에 `설정할 메타데이터 고르기`(이하 **설정 버튼**)가 새로 노출됩니다.


3. **메타 화면 전환 (**설정 버튼** 클릭 시)**
* 사용자가 **설정 버튼**을 클릭하면, 탐색 화면에서 선택(체크)된 MP3 파일 목록을 들고 `MetadataScreen`(메타 화면)으로 화면이 전환(Push Screen)됩니다.

---

### B. 메타 화면 (`MetadataScreen`)

1. **상단 및 하단 조작부**
* **우상단 버튼**: `닫기` 버튼 (클릭 시 메타 화면이 닫히고 직전 **탐색 화면**으로 복귀)
* **하단 버튼**: 기존 **설정 버튼**이 있던 자리에 `메타데이터 수정하기` 버튼(이하 **수정 버튼**) 배치


2. **메타데이터 설정 목록 영역**
* 최상단: `[x] 전체 항목 선택/해제` 체크박스 (기본값: 모두 선택됨)
* **공통 필드 (1차 읽기값 매핑 & 수정 가능 Input 제공)**
* `[x] 앨범명`: MP3 메타데이터에서 1차로 읽어온 값. 없으면 **현재 폴더명**으로 자동 매핑.
* `[x] 아티스트`: MP3 메타데이터에서 1차로 읽어온 값. 없으면 빈칸 유지.
* `[x] 연도`: MP3 메타데이터에서 1차로 읽어온 값. 없으면 빈칸 유지.


* **개별 필드 (입력창 없음)**
* `[x] 트랙명`: 파일명 기반 자동 정제 적용 예정 안내 표기
* `[x] 트랙번호`: MP3 파일명 오름차순 기준 순번 적용 예정 안내 표기

## 3. 핵심 비즈니스 로직 설계 (MP3 전용)

### A. MP3 파일명 정제 및 트랙명 추출 (요구사항 13)

* 확장자(`.mp3`)를 제외한 파일명 앞부분의 숫자로 된 트랙 번호 패턴(`n-`, `n)`, `n.`, `[n]` 등) 및 공백/구분자를 정규표현식으로 제거합니다.
* **정규표현식 예시**: `r'^\s*(\d+|\[\d+\])[\s._\-)]*'`
* **변환 예시**: `01 - Sony Music.mp3` $\rightarrow$ `Sony Music`

### B. MP3 트랙번호 부여 로직 (요구사항 12)

* 탐색 화면에서 선택된 **MP3 파일들만** 파일명 기준 오름차순으로 정렬합니다.
* 정렬된 MP3 파일 순서대로 `1`, `2`, `3` ... 순번을 부여합니다.

### C. 메타데이터 적용 및 완료/실패 처리 (요구사항 10, 11, 14, 15)

* **수정 버튼** 클릭 시 ID3 태그(`TALB`, `TPE1`, `TDRC`, `TIT2`, `TRCK`)를 일괄 작성합니다.
* **수정 성공 시**: 성공 알림 메시지를 표시하고 **탐색 화면**으로 자동 돌아갑니다.
* **수정 실패 시**: 실패 알림 메시지를 표시하고 **메타 화면** 상태를 그대로 유지합니다.
