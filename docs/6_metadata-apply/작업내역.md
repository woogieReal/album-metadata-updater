### 작업 내용
- `screens/metadata.py` — `MetadataService` import 및 `__init__`에서 인스턴스 생성
- `_apply_metadata()` 메서드 구현 (수정 버튼 핸들러)
  - 체크된 필드만 선별하여 파일별 `tags` dict 구성
  - `assign_track_numbers()`로 전체 파일의 트랙번호 순번 미리 계산 후 `track_map` dict로 관리
  - `selected_files` 순회하며 파일별 `write_tags(filepath, tags)` 호출
  - 트랙명은 파일마다 `clean_track_title(파일명)`으로 개별 계산
  - 실패 파일 수집 후 전체 성공이면 Toast + `pop_screen()`, 실패 있으면 에러 Toast + 화면 유지
- 실 MP3 파일 복사본으로 end-to-end 검증
  - `(Rudy Van Gelder Edition/1999 Digital Remaster)` suffix 제거 확인
  - 6개 파일 전체 트랙명·트랙번호·앨범명·아티스트·연도 정상 저장 확인

### 주요 결정 사항
- `track_map`을 루프 진입 전에 미리 계산
  - `assign_track_numbers()`가 전체 파일 목록 기준으로 순번을 부여하므로, 루프 내에서 매번 호출하면 항상 1번이 반환되는 오류 발생 가능
- `MetadataService`를 `__init__`에서 인스턴스화해 `_service`로 보유
  - 화면 내에서 여러 메서드가 공유하므로 매 호출마다 생성하지 않도록 함
- 체크되지 않은 필드는 `tags` dict에 키 자체를 추가하지 않는 방식으로 처리
  - `write_tags()`가 없는 키는 스킵하도록 설계되어 있으므로, 별도 분기 없이 자연스럽게 선택적 적용 가능
