# Album Metadata Updater

Python으로 작성된 TUI 기반 MP3 메타데이터 일괄 편집 도구입니다. 폴더 단위로 MP3 파일을 선택하고, 앨범명·아티스트·연도·트랙명·트랙번호를 한 번에 수정할 수 있습니다. `Textual`로 구현된 인터랙티브 터미널 UI와 `mutagen`을 사용한 ID3 태그 읽기/쓰기를 제공합니다.

## ✨ 주요 기능

- **TUI 기반 폴더 탐색**: 홈 디렉터리에서 시작하는 디렉터리 트리로 앨범 폴더를 탐색합니다. 앱 실행 위치(cwd)로 자동 포커스됩니다.
- **파일 트리 새로고침**: `새로고침` 버튼 또는 `r` 단축키로 펼쳐진 디렉터리 상태를 유지하면서 파일시스템의 최신 변경사항을 다시 불러옵니다.
- **MP3 파일 선택**: 선택한 폴더의 MP3 파일 목록을 표시하고, 전체 선택/해제 및 개별 선택을 지원합니다.
- **ID3 태그 일괄 수정**: 앨범명, 아티스트, 연도, 트랙명, 트랙번호를 선택적으로 일괄 적용합니다.
  - **트랙명 자동 정제**: 파일명에서 번호, 특수문자 등을 제거하고 깔끔한 제목을 자동 생성합니다.
  - **트랙번호 자동 부여**: 파일명 오름차순 기준으로 순번을 자동 계산합니다.
- **폴더 메타데이터 자동 로드**: macOS 확장 속성(xattr)에 저장된 `user.album`, `user.artist`, `user.year` 값을 자동으로 불러와 입력 필드에 채워줍니다.
- **앱 재시작**: `Ctrl+R` 단축키 또는 `앱 재시작` 버튼으로 터미널을 닫지 않고 프로세스를 재기동합니다. 개발 중 코드 수정사항을 바로 반영할 때 유용합니다.

## 🚀 설치 및 실행 방법

### 1. 사전 준비 사항

**Python 3.9 이상**이 설치되어 있어야 합니다.

```bash
# macOS (Homebrew)
brew install python
```

### 2. 저장소 클론

```bash
git clone https://github.com/woogieReal/album-metadata-updater.git
cd album-metadata-updater
```

### 3. 가상 환경 설정 및 패키지 설치

```bash
# 가상 환경 생성
python3 -m venv .venv

# 가상 환경 활성화
source .venv/bin/activate

# 의존성 패키지 설치
pip install -r requirements.txt
```

## 💻 사용 방법

### 간편 실행 스크립트 (macOS)

가상 환경 활성화와 앱 실행을 한 번에 처리합니다. 더블클릭 또는 터미널에서 실행 모두 가능합니다.

```bash
./run_app.command
```

### 직접 실행

```bash
source .venv/bin/activate
python main.py
```

### 단축키 및 컨트롤

- **`r`**: 파일 트리 / 파일 목록 새로고침 (펼쳐진 디렉터리 유지)
- **`Ctrl+R`**: 앱 재시작 (터미널을 닫지 않고 프로세스를 재기동해 코드 변경사항을 반영)
- **`새로고침` 버튼**: 파일시스템 변경사항 재스캔
- **`폴더 다시 선택` 버튼**: 파일 목록 화면에서 다시 폴더 탐색 화면으로 복귀
- **`앱 재시작` 버튼**: `Ctrl+R`과 동일하게 앱을 재기동

### 앱 사용 흐름

1. **탐색화면**: 디렉터리 트리에서 앨범 폴더를 선택하고 "현재 폴더 사용하기" 버튼을 누릅니다. (필요 시 `r` 또는 "새로고침"으로 파일 트리 갱신)
2. **파일 선택**: MP3 파일 목록에서 수정할 파일을 선택하고 "설정할 메타데이터 고르기" 버튼을 누릅니다.
3. **메타데이터 수정**: 수정할 항목(앨범명, 아티스트, 연도, 트랙명, 트랙번호)을 체크하고 값을 입력한 뒤 "메타데이터 수정하기" 버튼을 누릅니다.
